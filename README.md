# AngelBot

An early Discord bot built with JavaScript and Discord.js. This repository is a learning project with bot commands and event handlers.

## Project structure

The package entry point is `main.js`. `package.json` records the original dependencies, including Discord.js 12.

## Local development

Install dependencies with `npm install`, then review the bot configuration and command handlers before running `node main.js` in a development environment.

Use a separate development bot and keep its token outside committed files. The historical dependencies and Discord integration may require changes before use with current services.

## Validation

The `test` script is a placeholder that exits with an error; this repository does not currently provide an automated test suite.
